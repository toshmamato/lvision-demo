## Ishga tushirish
- `index.html` ni brauzerda oching, yoki
- VS Code'da Live Server orqali **Open with Live Server**.

## Tuzilma
- `index.html` — sahifa va mavzu (theme) skripti
- `css/style.css` — dizayn va qora/och mavzu
- `js/app.js` — mahsulotlar, savat, checkout, admin preview
